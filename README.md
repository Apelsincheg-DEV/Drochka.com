# Красный архив — версия 0.2

Статический сайт-энциклопедия на HTML, CSS и JavaScript. Визуальное направление: советский конструктивизм, плакатная геометрия, красный/кремовый/золотой цвета.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Интернет нужен только для открытия внешних ссылок в разделе источников; сам сайт работает локально.

## Что работает

- Каталог материалов по истории СССР, марксизму, коммунизму, социализму, политической мысли и персоналиям.
- Поиск по названиям, описаниям и текстам статей.
- Фильтры по категориям и сортировка.
- Просмотр статей в диалоговом окне.
- Избранное с сохранением в `localStorage`.
- Демонстрационный локальный профиль.
- Локальное добавление статьи: откройте окно «Войти», затем дважды щёлкните по кнопке профиля или нажмите на неё правой кнопкой мыши. Это временный редактор для прототипирования, не настоящая защищённая админ-панель.
- Адаптивная вёрстка для мобильных экранов.

## Важно: текущие ограничения

Это **фронтенд-прототип**, а не развёрнутый многопользовательский сервис. Избранное, локальный профиль и пользовательские статьи хранятся только в браузере. Они не синхронизируются между устройствами и могут быть удалены очисткой данных браузера. Локальный редактор не защищён и не предназначен для публичного размещения.

## Предлагаемая архитектура следующего этапа

- Frontend: оставить текущий интерфейс и перевести каталог на API.
- Backend: Node.js + Express (или другой серверный стек).
- База данных: PostgreSQL для пользователей, статей, категорий, источников, избранного и истории правок.
- Аутентификация: безопасные сессии или проверенный провайдер авторизации; пароли не хранить в открытом виде.
- Роли: читатель, редактор, администратор. Проверка прав должна выполняться на сервере, а не только скрытием кнопок в интерфейсе.
- Админ-панель: создание/редактирование/архивация статей, управление категориями и источниками, журнал изменений, черновики и публикация.
- Публикация: домен, HTTPS, хостинг, резервные копии, модерация и защита от спама.

## Структура

- `index.html` — разметка и основные разделы.
- `css/styles.css` — оформление.
- `js/articles.js` — начальные статьи и хронология.
- `js/app.js` — поиск, фильтры, избранное, диалоги и локальный редактор.

## Редакционный принцип

Левый фокус проекта совместим с точной работой с источниками: указывайте автора, дату, происхождение документа, отделяйте факты от интерпретаций и обозначайте спорные вопросы. Внешние ссылки требуют отдельной проверки перед публичным запуском.
